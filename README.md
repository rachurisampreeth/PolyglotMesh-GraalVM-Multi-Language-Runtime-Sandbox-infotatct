# PolyglotMesh-GraalVM-Multi-Language-Runtime-Sandbox-infotatct

## Setup Instructions

### Requirements
- Python 3
- Git
- Visual Studio Code (recommended)

### Running the sample programs

Clone the repository:

```bash
git clone https://github.com/rachurisampreeth/PolyglotMesh-GraalVM-Multi-Language-Runtime-Sandbox-infotatct.git
```

Open the project folder:

```bash
cd PolyglotMesh-GraalVM-Multi-Language-Runtime-Sandbox-infotatct
```

Run a sample program:

```bash
python samples/hello.py
```

### Available Sample Scripts

| File | Description |
|---|---|
| hello.py | Prints Hello World |
| add.py | Adds two numbers |
| loop.py | Demonstrates a loop |
| even_odd.py | Checks whether a number is even or odd |
| multiply.py | Multiplies two numbers |
