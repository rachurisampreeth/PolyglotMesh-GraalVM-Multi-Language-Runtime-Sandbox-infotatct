# PolyglotMesh

GraalVM multi-language runtime sandbox: run Python and JavaScript inside the same
Spring Boot JVM, with a React + Monaco IDE dashboard.

## Structure
- backend/   Spring Boot 3 + WebFlux + GraalVM polyglot (port 7070)
- frontend/  React + Vite + Monaco (port 7071)
- samples/   sample scripts for testing
- docs/      screenshots, slides, test documents
- CONTRACTS.md  API and team rules (read this first)
